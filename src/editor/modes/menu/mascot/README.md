# Персонажи меню

Модуль показывает персонажа и реагирует на события меню. Выбор блюд остаётся в
`guest-selection`; настройки персонажа входят в `MenuContent.mascot`.

## Устройство

- `characters/bun/character.tsx` — SVG Булочки с отдельными частями тела и выражениями лица.
- `characters/bun/animations.ts` — позы и движения Булочки, включая статичные варианты.
- `characters/mochi/` — розовый Моти с листочками: мягкое сжатие, поклон и пружинящий прыжок.
- `characters/pepper/` — коралловый Перчик: покачивание, взмах рукой и короткий танец.
- `registry.ts` — каталог компонентов и ключей перевода.
- `behavior.ts` — соответствие событий эмоциям, длительности и переходы.
- `use-mascot.ts` — один контроллер на гостевую панель, общий для кнопки и окна.
- `mascot.tsx` — отображение персонажа и сообщения.
- `game/model.ts` — правила игры «Найди пару»: перемешивание, совпадения, интерес и защита от повторных действий.
- `game/pair-game.tsx` — шесть карточек, реакции персонажа и повтор игры; используется гостевой панелью и sidebar.
- `use-mascot-motion.ts` — системное уменьшение движения и остановка в скрытой вкладке.
- `settings-panel.tsx` — настройки и независимая демонстрация эмоций.

Контракт настроек и проверка допустимых ID находятся в
`functions/src/domain/menu/mascot.ts`; этот контракт используется редактором и
публикацией. Сохраняются только `enabled`, `characterId` и `animations`.
Настроение, номер реакции и таймеры существуют только в интерфейсе.

Новая реакция заменяет текущую. Завершение предыдущей реакции не может завершить
новую. Выключение анимаций оставляет выражения лица, выключение персонажа
сохраняет кнопку рекомендаций.

При каждой реакции компонент персонажа пересоздаётся для повторного проигрывания.
Анимированные SVG-группы должны задавать явную начальную позу: `initial={false}`
подавляет запуск при монтировании вне анимированного родителя, как в публичном меню
и предпросмотре. Использовать его следует только при выключенной анимации.
При проверке движения сравнивайте трансформации в нескольких кадрах: смена
`data-mood` подтверждает эмоцию, но сама по себе не подтверждает проигрывание.

## Добавление персонажа

На опубликованном сайте игра хранит состояние в гостевой сессии общего layout:
закрытие панели и SPA-переходы между страницами не сбрасывают прогресс.
Предпросмотр имеет отдельную сессию, sidebar — отдельную демонстрацию.
Полная перезагрузка начинает новую игру; выбор блюд восстанавливается из localStorage.
Совпадение добавляет
34 пункта интереса (максимум 100); повтор игры сохраняет интерес. Таймер закрывает
неподходящую пару через секунду и очищается при закрытии блока. Игра не меняет
заказ, черновик или опубликованный контент. С выключенным персонажем игра скрыта;
при уменьшении движения она работает со статичными позами.

1. Добавить ID в общий контракт.
2. Создать папку в `characters/` с компонентом, принимающим `MascotCharacterProps`,
   и собственными анимациями для пяти состояний. Предусмотреть статичные позы.
3. Зарегистрировать компонент в `registry.ts` и добавить название/описание в ru/en/kz.
4. Проверить маленький размер, светлые и тёмные шаблоны, быстрые действия,
   уменьшение движения, сохранение и публикацию.

Каталог панели строится из общего списка ID. Шаблоны меню и выбор блюд при
добавлении персонажа не меняются.
